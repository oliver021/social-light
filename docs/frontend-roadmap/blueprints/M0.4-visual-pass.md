# M0.4 — Visual quality pass over every tab

**Goal:** every screen is built from the M0.2 tokens and the M0.3 primitives, so Home,
Communities, Marketplace, Reels, Profile and the Messenger look like one product
(UX-DIAGNOSIS §G: "marketplace, reels and groups look like separate apps"). This is the
last pre-step before features.

All paths relative to `src/main_fronted/src/`. The workflow may run this milestone as
**parallel parts**, one per file group in §4; each part touches only its own files.
`index.css` and `scripts/check-rules.mjs` belong to part P0 only.

## 1. Colour migration table (Tailwind)

Replace raw palette classes by meaning, not by shade. Pairs collapse into one class
because the token already switches with the theme.

| Today (typical) | Replace with |
|---|---|
| `text-zinc-900 dark:text-zinc-100`, `text-zinc-800 dark:text-zinc-200`, `text-zinc-950 dark:text-white` | `text-fg` |
| `text-zinc-600 dark:text-zinc-400`, `text-zinc-500 dark:text-zinc-400`, `text-zinc-700 dark:text-zinc-300` | `text-muted` |
| `text-zinc-400 dark:text-zinc-500`, `text-zinc-400` on captions/timestamps | `text-subtle` |
| `bg-white dark:bg-zinc-950`, `bg-white dark:bg-zinc-900`, `bg-white/95 dark:bg-zinc-950/95` | `bg-surface` (keep an opacity suffix only on the sticky bars: use the `color-mix` from M0.3) |
| `bg-zinc-50 dark:bg-zinc-950/60` on the page | `bg-page` |
| `bg-zinc-100 dark:bg-zinc-900`, `bg-zinc-50 dark:bg-zinc-900` (inputs, chips, rows) | `bg-surface-2` |
| `hover:bg-zinc-100 dark:hover:bg-zinc-900` (and `-800`) | `hover:bg-surface-2` |
| selected / pressed rows | `bg-surface-3` or `bg-primary-soft text-primary` for the active nav item |
| `border-zinc-200 dark:border-zinc-800`, `border-zinc-100 dark:border-zinc-850`, `divide-zinc-*` | `border-line`, `divide-line` |
| focused / emphasised borders | `border-line-strong` |
| `text-emerald-*`, `text-green-*` | `text-success` (`bg-success-soft` for backgrounds) |
| `text-amber-*` | `text-warning` |
| `text-red-*`, `text-rose-*` | `text-danger` |
| `text-blue-*`, `text-sky-*`, `text-indigo-*` | `text-primary` |
| `to-zinc-*` in an image overlay gradient | `from-black/60 to-transparent` (overlays on media are the one place black/white are correct) |

Allowed raw colours after this milestone: `text-white`, `bg-black`, `bg-black/NN`,
`from-black/NN`, `to-transparent` — only on top of images/video. Everything else is a
token.

## 2. Primitive adoption (every tab)

- Each top-level card is a `Surface`; each card title is a `SectionHeader`; tabs other
  than Home start with a `PageHeader` (Communities, Marketplace, Reels, Profile).
- Every list that loads shows a skeleton from `Skeletons.tsx` while its first load is
  pending (Groups list, Events widget, People widget, Marketplace grid, Reels, Profile
  posts, Notifications menu, Messenger thread list). Use the hook's existing loading
  flag; if a hook has none, add `loading` state in the hook (set true before the first
  request, false in `finally`) and test it.
- Every empty list uses `EmptyState` with one forward action where one exists.
- Every avatar is a `UserAvatar`; every "person + name + handle" row is a `UserLine`.
- Every create form dialog (create group, create event, new listing, upload reel, add
  story, edit profile) is a `ResponsiveDialog`.

## 3. Visual rules

- **Rhythm:** card padding `var(--ui-card-pad)`; gap between cards `var(--ui-gap)`;
  inside a card use multiples of 4px (Tailwind `gap-2/3/4`, MUI `gap: 1/1.5/2`).
- **Radius:** cards `rounded-card`, dialogs/media/chat windows `rounded-lg`, inputs and
  small buttons `rounded-sm`, pills/avatars `rounded-full`. No other radius values.
- **Type:** page title `--ui-fs-2xl` display font; section title `sectionTitleSx`;
  body `--ui-fs-base`; meta `--ui-fs-xs` `text-subtle`. No `text-[13px]`-style arbitrary
  sizes; use `text-xs/sm/base/lg` or the tokens.
- **Buttons:** at most one contained primary button per card; secondary actions are
  `outlined` or `text`. Follow/Join/Connect are pills (`pillButtonSx`) and show their
  state ("Following", "Joined") with a different variant, not only a different colour.
- **Icons:** lucide, `size={18}` in buttons and rows, `size={20}` in navigation,
  `strokeWidth={1.75}` everywhere. Decorative icons get `aria-hidden`.
- **Media:** post images `max-height: 560px`, `object-fit: cover`, `rounded-lg`, with a
  real `alt` (post text truncated to 120 chars, or "Image posted by {name}"); video has
  `controls` and a poster colour `bg-black`.
- **States:** every clickable row/card has hover (`bg-surface-2`), focus-visible ring,
  and pressed (`bg-surface-3`) states; disabled controls use MUI `disabled`, never only
  opacity.
- **Motion:** transitions use `var(--ui-dur) var(--ui-ease)`. Add to `index.css`:
  `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: .01ms !important; transition-duration: .01ms !important; } }`.
- **Accessibility leftovers from KNOWN-ISSUES:** A-1 (images without `alt`), A-2 (30
  buttons all named "Connect": name them "Follow {name}"), A-3/A-4 (low-contrast helper
  text: the tokens fix it once the classes are migrated), U-1/U-2 (chat window covering
  the top bar on phones: give the Messenger windows `top: calc(var(--ui-header-h) + 8px)`
  as their maximum extent and `max-height: calc(100dvh - var(--ui-header-h) - var(--ui-bottomnav-h) - 16px)` below 640px).
