# M0.3 — UI primitives and the layout shell

**Goal:** the building blocks every feature milestone needs exist once, in
`components/ui/`, and the page layout is one component instead of a grid inlined in
`App.tsx`. The two giant components (`Navbar.tsx` 723 lines, `PostCard.tsx` 463 lines)
are split along their existing sections so M1–M3 can change one piece at a time.
**No visible behaviour change** except what is listed under "Layout".

All paths relative to `src/main_fronted/src/`. Use the tokens/`T` map from M0.2 for
every colour, radius and shadow.

## 1. Primitives (`components/ui/`, one file each, each exported by name)

| Component | Props | Notes |
|---|---|---|
| `Surface` | `as?: 'section'\|'article'\|'div'`, `padding?: 'none'\|'sm'\|'md'`, `interactive?: boolean`, `aria-label?`, `children`, `sx?` | The card. Uses `cardSx`. `interactive` adds hover `shadow-1` + `border-strong`. Replaces ad-hoc `Paper`/`Card`/`ui-card` wrappers going forward. |
| `SectionHeader` | `title`, `subtitle?`, `action?: ReactNode`, `as?: 'h2'\|'h3'` | Title uses `sectionTitleSx`; real heading element for screen readers. |
| `PageHeader` | `title`, `description?`, `actions?: ReactNode` | Top of each tab (Communities, Marketplace, Reels, Profile). `h1`. |
| `UserAvatar` | `name`, `src?`, `size?: 'xs'\|'sm'\|'md'\|'lg'\|'xl'` (24/32/40/56/96), `onClick?` | `src` goes through `mediaUrl()`. Fallback: initials on `T.primarySoft`. `alt={name}` always. With `onClick` it renders a `ButtonBase` with `aria-label="Open {name}'s profile"`. |
| `UserLine` | `name`, `handle?`, `avatarSrc?`, `meta?: ReactNode` (e.g. time), `onOpen?`, `trailing?: ReactNode`, `size?` | Avatar + name + `@handle · meta`. Hides an empty handle. Name is a button when `onOpen` is set. Used by post headers, comments, people rows, chat headers. |
| `ConfirmDialog` | `open`, `title`, `body?`, `confirmLabel`, `destructive?`, `onConfirm: () => Promise<void>`, `onClose` | Confirm button shows a spinner while `onConfirm` runs; on rejection shows the error text inside the dialog (`role="alert"`) and stays open; on success closes. Cancel is the default-focused button when `destructive`. |
| `OverflowMenu` | `label` (accessible name, e.g. "More actions for this post"), `items: { id, label, icon?, onSelect, danger?, hidden? }[]` | Kebab `IconButton` (`MoreHorizontal` from lucide) + MUI `Menu`. Renders nothing when every item is hidden. `danger` items use `T.danger`. |
| `AsyncButton` | MUI `ButtonProps` + `onClick: () => Promise<unknown>` | Disables and shows a 16px spinner while pending; ignores clicks while pending. |
| `StatusChip` | `label`, `tone?: 'neutral'\|'primary'\|'success'\|'warning'\|'danger'` | Small pill using `T.*Soft` background + `T.*` text. |
| `InlineError` | `message`, `onRetry?` | `role="alert"`, danger text, optional "Try again" button. |
| `ResponsiveDialog` | MUI `DialogProps` + `title`, `actions?` | `fullScreen` below `sm` (640px), title row with a close `IconButton` (`aria-label="Close"`). All create/edit forms use it from now on. |
| `Skeletons.tsx` | `PostSkeleton`, `ListSkeleton({ rows })`, `CardGridSkeleton({ count })` | Move `FeedSkeleton` out of `FeedsTab.tsx` into `PostSkeleton`. MUI `Skeleton` with `animation="wave"`. |
| `RelativeTime` | `iso?: string \| null` | `<time dateTime={iso}>` with the text from the existing `timeAgo` helper in `api/mappers.ts` (move `timeAgo` to `components/ui/time.ts` and re-export from mappers so imports keep working). Renders nothing for a missing date. |

Also add `components/ui/index.ts` re-exporting all of them and the tokens.

## 3. Layout shell (`components/layout/AppShell.tsx`)

Move the logged-in page structure out of `App.tsx` into `AppShell`. `App.tsx` keeps only
providers, the theme, the auth gate and `<AppShell />`.

Use CSS grid (Tailwind classes or `sx`), not MUI `Grid`:

| Width | Columns | Left rail | Right rail |
|---|---|---|---|
| < 768 | `minmax(0,1fr)` | in the drawer | below main (as today on phones) |
| 768–1199 | `240px minmax(0,1fr)` | sticky | under the left rail (as today) |
| ≥ 1200, `layout: 'feed'` | `264px minmax(0,640px) 320px`, centred, `gap: 24px` | sticky | sticky |
| ≥ 1200, `layout: 'wide'` | `264px minmax(0,1fr)` (main spans main + right) | sticky | hidden |

- Max content width 1280px, side padding 16px (24px ≥ 1200).
- Rails: `position: sticky; top: calc(var(--ui-header-h) + 16px); max-height: calc(100dvh - var(--ui-header-h) - 32px); overflow-y: auto`.
- Main column: `display: flex; flex-direction: column; gap: var(--ui-gap); min-width: 0`.
- Phone: `padding-bottom: calc(var(--ui-bottomnav-h) + env(safe-area-inset-bottom))`;
  bottom nav uses `env(safe-area-inset-bottom)` padding.
- The Messenger stays mounted outside the grid (as today).
- Header: `Navbar` gets `position: sticky; top: 0; height: var(--ui-header-h)`, surface
  background with `backdrop-filter: blur(8px)` at 90% opacity via `color-mix(in srgb, var(--ui-surface) 90%, transparent)`.
- A skip link "Skip to content" as the first focusable element, targeting `<main id="main">`.

This fixes KNOWN-ISSUES U-3 (768px sidebar overlapping the composer) if the columns
are right: verify by reading the classes, and note it in the report for the human check.

## 5. Tests

- One test file per primitive with real assertions:
  - `ConfirmDialog`: confirm calls `onConfirm` and closes; a rejected `onConfirm` shows the
    message with `role="alert"` and keeps the dialog open; Cancel calls `onClose` only.
  - `OverflowMenu`: opens by keyboard (Enter on the button), runs `onSelect`, renders
    nothing when all items are hidden.
  - `UserAvatar`: initials fallback; `alt`; with `onClick` it is a button named "Open X's profile".
  - `AsyncButton`: double click while pending calls the handler once.
  - `RelativeTime`: renders `<time dateTime>`; nothing for `null`.
- **Characterisation tests written BEFORE the split** (commit order inside the milestone:
  write them, see them pass on the old code, then split, see them still pass):
  - `PostCard.test.tsx`: renders author name, content, the like/comment/share buttons by
    role; typing a comment and pressing the send button calls `addComment(postId, text)`.
  - `Navbar.test.tsx`: typing in search shows the matching person/post; the bell button
    opens the notifications list; the account menu has "Log out" which calls `logout`.
- `AppShell.test.tsx`: renders `main#main`, the skip link, and one nav item per `TABS`
  entry with its label.
