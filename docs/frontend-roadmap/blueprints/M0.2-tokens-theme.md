# M0.2 — Design tokens and a single MUI theme

**Goal:** one set of design tokens, used by both Tailwind classes and MUI `sx`, with
light and dark values. After this milestone there is no hex colour in components and no
`violet-*`/`fuchsia-*` class (today `violet` is secretly remapped to blue in
`index.css`, which makes every class lie about its colour).

All paths relative to `src/main_fronted/src/`.

## Today (measured 2026-10-24)

- `App.tsx` builds the MUI theme inline with 9 hard-coded hex values that duplicate
  `index.css`.
- 36 more hex literals in components (Marketplace amber, Auth screen, story ring, reel
  and composer gradients, Sidebar badge).
- 66 `violet-*`/`fuchsia-*` classes; `index.css` remaps `violet` to blue and `fuchsia`
  to purple, and remaps `zinc-800…950` to custom greys.
- `components/ui/tokens.ts` has 4 sx presets on 7 `--ui-*` variables.

## 2. Tailwind mapping (`index.css`)

Add an `@theme inline` block so the tokens become utilities:

```css
@theme inline {
  --color-page: var(--ui-page);
  --color-surface: var(--ui-surface);
  --color-surface-2: var(--ui-surface-2);
  --color-surface-3: var(--ui-surface-3);
  --color-line: var(--ui-border);
  --color-line-strong: var(--ui-border-strong);
  --color-fg: var(--ui-text);
  --color-muted: var(--ui-muted);
  --color-subtle: var(--ui-subtle);
  --color-primary: var(--ui-primary);
  --color-primary-hover: var(--ui-primary-hover);
  --color-on-primary: var(--ui-on-primary);
  --color-primary-soft: var(--ui-primary-soft);
  --color-accent: var(--ui-accent);
  --color-accent-soft: var(--ui-accent-soft);
  --color-success: var(--ui-success);
  --color-success-soft: var(--ui-success-soft);
  --color-warning: var(--ui-warning);
  --color-warning-soft: var(--ui-warning-soft);
  --color-danger: var(--ui-danger);
  --color-danger-soft: var(--ui-danger-soft);
  --radius-sm: var(--ui-radius-sm);
  --radius-card: var(--ui-radius);
  --radius-lg: var(--ui-radius-lg);
  --shadow-1: var(--ui-shadow-1);
  --shadow-2: var(--ui-shadow-2);
  --shadow-3: var(--ui-shadow-3);
}
@utility brand-gradient { background-image: linear-gradient(to top right, var(--ui-primary), var(--ui-accent)); }
@utility brand-ring { background-image: linear-gradient(to top right, var(--ui-accent), var(--ui-primary)); }
```

This gives `bg-surface`, `text-muted`, `border-line`, `bg-primary-soft`, `rounded-card`,
`shadow-2`, `brand-gradient` and so on. Keep the existing `ui-card`, `ui-section-title`
and `ui-muted` utilities, rewritten on the new tokens. `--ui-surface`, `--ui-border`,
`--ui-text`, `--ui-muted`, `--ui-radius`, `--ui-card-pad` keep their names, so existing
`var(--ui-…)` uses keep working.

**Remove** the `--color-violet-*` and `--color-fuchsia-*` remaps from `@theme`. **Keep**
the `--color-zinc-*` remaps for now (M0.4 migrates the 420 zinc uses; removing the remap
first would shift dark-mode greys everywhere at once).

## 3. `components/ui/theme.ts` (new; the only file allowed to hold hex values besides `index.css`)

```ts
export const TOKENS = { light: { page: '#f6f7f9', surface: '#ffffff', … }, dark: { … } } as const;
export function buildTheme(mode: 'light' | 'dark'): Theme
```

- `TOKENS` holds exactly the colour values of §1 (camelCase keys: `surface2`,
  `primaryHover`, `onPrimary`, `primarySoft`, …).
- `buildTheme` moves everything that is in `App.tsx`'s `createTheme` today (breakpoints
  `sm 640, md 768, lg 1200, xl 1536` must stay) and derives the palette from `TOKENS`:
  `primary.main = primary`, `primary.contrastText = onPrimary`, `secondary.main = accent`,
  `error.main = danger`, `success.main = success`, `warning.main = warning`,
  `background.default = page`, `background.paper = surface`, `text.primary = text`,
  `text.secondary = muted`, `divider = border`.
- `shape.borderRadius = 8`.
- Typography: body Inter; `h1…h6` Space Grotesk; `button { textTransform: 'none', fontWeight: 600 }`;
  `body1 15px`, `body2 13px`, `caption 12px`.
- Component overrides (use `var(--ui-…)` strings in `styleOverrides`, not hex):
  - `MuiButton`: `defaultProps.disableElevation`; root `borderRadius: var(--ui-radius-sm)`,
    `minHeight: 36`; `sizeLarge` `minHeight: 44`; a `variants` entry for `{ props: { variant: 'contained', color: 'primary' } }` with `'&:hover': { bgcolor: 'var(--ui-primary-hover)' }`.
  - `MuiIconButton`: focus-visible ring `0 0 0 2px var(--ui-focus)`.
  - `MuiCard`, `MuiPaper`: `backgroundImage: 'none'`, `boxShadow: 'none'`; Card border `1px solid var(--ui-border)`, radius `var(--ui-radius)`.
  - `MuiDialog` paper: radius `var(--ui-radius-lg)`, shadow `var(--ui-shadow-3)`.
  - `MuiMenu`/`MuiPopover` paper: radius `var(--ui-radius-sm)`, border, shadow `var(--ui-shadow-2)`.
  - `MuiTooltip`: `fontSize: var(--ui-fs-xs)`.
  - `MuiChip`: radius `var(--ui-radius-full)`, `fontWeight: 500`.
  - `MuiOutlinedInput`: background `var(--ui-surface-2)`, radius `var(--ui-radius-sm)`, notched outline `var(--ui-border)`, focused `var(--ui-primary)`.
  - `MuiAvatar`: `fontFamily` display, `fontWeight: 600`.
- `App.tsx`: `const theme = useMemo(() => buildTheme(darkMode ? 'dark' : 'light'), [darkMode]);`
  and delete the inline `createTheme`. Also use `buildTheme` for the logged-out branch.

| Today | Replace with |
|---|---|
| `text-violet-*`, `bg-violet-*`, `border-violet-*` (blue in practice) | `text-primary`, `bg-primary` / `bg-primary-soft`, `border-primary` (pick by shade: 50–200 → `-soft`, 400–700 → base) |

## 6. Tests

- `components/ui/theme.test.ts`:
  - **Parity:** read `src/index.css` with `fs.readFileSync`, parse the `:root { … }` and
    `.dark { … }` blocks, and assert every colour in `TOKENS.light`/`TOKENS.dark` equals
    the matching `--ui-*` value. This is what keeps the two sources in sync.
  - **Contrast:** a small WCAG relative-luminance helper; assert ≥ 4.5 for `text`,
    `muted`, `subtle` on `surface` and on `page`, and for `onPrimary` on `primary`, in both
    themes; ≥ 3 for `primary` on `surface` (UI component contrast).
  - `buildTheme('dark').palette.mode === 'dark'`, `palette.primary.main === TOKENS.dark.primary`,
    breakpoints `md === 768`.
